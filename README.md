# subscription_service - Тестовое задание Junior Golang Developer Effective Mobile.

В данном проекте создан REST-сервис для агрегации данных об онлайн подписках пользователей.

## Были реализованы:

1. HTTP-ручка для CRUDL-операций над записями о подписках. 
Каждая запись содержит:
- Название сервиса, предоставляющего подписку
- Стоимость месячной подписки в рублях
- ID пользователя в формате UUID
- Дата начала подписки (месяц и год)
- Дата окончания подписки
2. HTTP-ручка для подсчета суммарной стоимости всех подписок за
выбранный период с фильтрацией по id пользователя и названию подписки
3. СУБД – PostgreSQL.
4. Код покрыт логами.
5. Вынесены конфигурационные данные в .env/.yaml-файл
6. Запуск сервиса с помощью docker compose

## Чтобы запустить код можно воспользоваться:
- Командой "docker-compose up --build".
